# 实施计划：#135 a11y 合规

规范已核对（Material 无障碍 + WCAG AA，非 BotC 规则域）。一个 PR，5 commit，关闭 #135。

## Commit 1 — 圆环 Semantics + 减弱动效（核心 a11y）
`app_motion.dart`：新增 `AppMotion.resolve(BuildContext, Duration) → Duration`（`MediaQuery.disableAnimationsOf` 为真 → 退化为 `fast` 150ms）。
`seat_ring.dart`：
- `didChangeDependencies` 读 reduce-motion 缓存为 `_reduceMotion`，initState/didUpdateWidget 的 controller 时长经 `AppMotion.resolve` 解析（死亡/常规签名动画在减弱动效下降级为快速淡入）。
- **Stack 叠加每座位透明 `Semantics` 节点**（Positioned 覆盖命中区，`button:true` + `label` + `onTap`/`onLongPress` 转发回调；透明 `SizedBox` 不拦截指针，sighted 点击仍走底层 GestureDetector）。
`seat_ring_player.dart`：新增 `semanticLabel` getter（纯函数：「X号 name。存活/已死亡。信任：level。我。疑似被毒。矛盾标记。」），供 Semantics label，可单测。

## Commit 2 — 命中测试最近中心（13-15 人局重叠 bug）
`seat_ring_layout.dart` `hitTest`：当前命中区重叠时恒返首个 → 改为**返距离最近且 ≤ hitRadius 的中心**（修「恒判首个」偏差；非重叠场景结果不变）。

## Commit 3 — 对比度（blood 文字 + 死亡色）
`app_colors.dart` + `game_colors.dart`：新增 `bloodBright`（提亮血红，~5:1 on bgSurface1 达 AA），`blood` 不变（仍用于填充/图标/边框/大字）。
- 切换所有「blood 作小号正文/标题/caption 色」→ `bloodBright`（player_detail/reasoning_dashboard/role_matrix/voting_panel/contradiction_panel/dependency_chain/confirm_step/player_count_step/game_board_page 的小字处；Icon/border/alpha 不动）。
- 死亡玩家 `AppColors.textDisabled`(2.9:1 + 语义错配) → `AppColors.textPrimary.withValues(alpha:0.45)`（nomination_entry_sheet 的 isDead 文字；app_theme hintStyle 不动——hint 本就该弱化）。

## Commit 4 — 全局 Semantics
- `_InfoRow` 可靠性圆点（`Icons.circle`）包 `Semantics(label: 可靠性描述)`（player_detail）。
- icon-only 按钮 tooltip 查漏补缺（扫一遍 game_board/home/player_detail/reasoning）。

## Commit 5 — 测试
- `seat_ring_player_test`：`semanticLabel` 各字段组合（存活/死亡/我/毒/矛盾）。
- `seat_ring_layout_test`：hitTest 重叠时返最近（两中心等距偏一侧 → 返更近者），非重叠不变。
- `seat_ring_test`：减弱动效下 controller.duration == fast；每座位 Semantics 节点存在（按 label 查找）。
- 对比度：断言 `bloodBright` 对 `bgSurface1` 的 WCAG 对比 ≥ 4.5（内联对比计算）。
