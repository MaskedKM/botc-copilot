# 🩸 BotC Copilot

> Blood on the Clocktower 对局推理助手 — 不只是笔记，而是推理引擎。

## 为什么做这个？

现有 BotC 玩家工具都停留在"电子笔记本"层面——记录信息，但不帮你分析。
BotC 的核心乐趣在于**信息网络的交叉推理**：角色 A 的信息 × 角色 B 的信息 → 谁在说谎？
没有任何工具帮你做这个推理。BotC Copilot 要解决这个问题。

## 核心功能（规划中）

- 🪑 **动态座位圆环** — 马蹄形布局，死亡自动收缩，邻座关系动态重算
- 📝 **结构化信息录入** — 按角色类型自动适配输入模板，3 次点击完成
- 🧠 **推理引擎** — 自动矛盾检测、信息可靠性追踪、排除法追踪器
- 🗳️ **投票分析** — 投票模式可视化，阵营暴露检测
- 🔍 **角色交叉矩阵** — 声明冲突一目了然
- 📊 **复盘模式** — 时间线回放、信息树可视化

## 技术栈

- Flutter / React Native（跨平台 iOS + Android）
- SQLite（离线优先）
- 自绘座位圆环（Canvas/SVG）
- 可选 LLM 辅助分析（Phase 2）

## 开发阶段

- [ ] Phase 1 — MVP：座位圆环 + 每日信息记录 + 本地持久化
- [ ] Phase 2 — 推理引擎：矛盾检测 + 可靠性追踪 + 排除法
- [ ] Phase 3 — 高级功能：逻辑链编辑器 + 复盘 + AI 辅助
