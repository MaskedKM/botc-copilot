# BotC Copilot — 整体视觉风格规范

> 本文档是 App 的**唯一视觉权威**。所有 UI 实现（Flutter `ThemeData`、组件、插画、动效）以此为准。
> 模式：**Operate**（用户在对局任务中）——扫读性、一致性、录入速度优先；哥特氛围通过配色、材质、字体和签名动效承载，绝不干扰任务。

---

## 一、设计命题（Direction Contract）

**THESIS**：这不是一个"做成了暗色的记录 App"，而是**玩家自己的猎魔手札**——Ravenswood Bluff 镇民在烛光下秘密记录的推理笔记。视角必须严格锁定在**玩家**：说书人的魔典（Grimoire）装的是全场秘密身份，玩家手里没有它，也不该有它；玩家拥有的是零散的信息、自己的角色能力、和一本越记越厚的手札。类别默认做法（普通列表 + 头像圆圈 + Material 蓝紫主题）被明确拒绝。

**OWN-WORLD**：
- **核心隐喻：座位圆环 = 小镇钟楼钟面**。镇民围坐在钟楼下，玩家是钟面上的刻度/数字，昼夜更替是钟针转动，死亡是蜡烛熄灭。BotC 的英文名就叫 *Clocktower*——钟面是这个世界最诚实、最有辨识度的形状，且它正好就是我们的核心交互组件。
- **手札感**：记录的形态是"墨水写入纸面"——录入即落笔，矛盾检测是"手札自动圈出的疑点"。玩家是说书人棋盘上努力求真的镇民，不是全知的记录员。
- 材质：深夜墨紫的"皮质封面"底、烛光金的描边与刻度、羊皮纸色的文字、血色的邪恶/危险标记。
- 抽掉所有内容后仍可辨认：墨紫底 + 金色细线（hairline）+ 衬线标题 + 钟面圆环。

**STORY**：玩家打开 App，感觉自己在烛光下翻开自己这局的手札；每一次记录都是"落笔"，每一次推理都是"翻回去交叉比对"，矛盾警告是"手札边角自动浮现的疑点批注"。

**FIRST VIEWPORT**（对局主界面）：屏幕上半部是占主导地位的钟面座位圆环（直径约为屏宽 85%），顶部细条显示"第 N 天 · 昼/夜"（以日月刻度表达），下半部是当日信息面板（可上滑展开）。主要操作（记录当日信息）以金边主按钮置于面板顶部。

**FORM**：Operate 模式下的"仪式化工具"——标准平台导航骨架（底部 Tab / NavigationBar），内部内容区使用手札语汇（衬线标题、金色刻度分隔线、钟面图形）。

### 候选世界推导记录（备查）

从 BotC 玩家熟悉的文化世界推导出 7 个候选，合并同类后：

| 候选 | 一句话理由 | 结论 |
|------|-----------|------|
| **玩家手札 + 钟楼钟面** | 手札是玩家真实会带的东西（纸笔正是被替代物）；钟面 = 座位圆环，隐喻与交互合一 | ✅ **选定** |
| 说书人魔典（Grimoire） | 氛围最贴 BotC，但**视角错误**：魔典是说书人的秘密道具，玩家无权翻阅 | 否决（视角不符，仅借"烛光下书写"的书写感） |
| 哥特教堂彩窗 | 氛围强，但彩窗色块与信息密度冲突 | 否决（仅借"金色描边"细节） |
| 蜡封与羊皮纸 | 仪式感强，但浅羊皮纸底违背"暗色护眼"硬约束 | 否决（借蜡封作"处决"图标记号） |
| 塔罗/奥秘卡牌 | 角色卡天然契合，但卡牌语汇在 Operate 模式下过重 | 部分借用（玩家详情卡的角色展示） |
| 烛光 | 是氛围光源而非系统 | 并入主方向（金色即烛光色） |
| 血与墨 | 只有两种材料，撑不起语义系统 | 并入主方向（血红色 = 邪恶/死亡） |
| 占星罗盘 | 与钟面近亲但指向"占卜"而非"时间/座位" | 并入主方向 |

> 注：色彩基调（深紫/深蓝底 + 金色点缀）已由 AGENTS.md 钉死，本次推导决定的是**渲染方式与世界完整度**，而非重新选色。

## 二、色彩系统

### 2.1 色彩策略

**Drenched（浸染式暗色底）+ Restrained accent（克制的金）**：整个界面浸在深夜墨紫中，金色只用于主操作、当前状态、钟面刻度——不撒得到处都是。状态语义色自成一族，与金色严格区分。

### 2.2 基础色板（暗色主题为唯一必做方案）

| Token | Hex | 用途 |
|-------|-----|------|
| `bg-base` | `#0D0B1A` | 屏幕最底层（"皮革封面"） |
| `bg-surface-1` | `#151226` | 卡片、面板 |
| `bg-surface-2` | `#1D1936` | 抬升面板、底部弹层 |
| `bg-surface-3` | `#262048` | 最高层（模态、选中态底色） |
| `line-hairline` | `#3A3462` | 默认分隔线 |
| `line-gold` | `#C9A24B` @ 40% | 仪式感分隔线（标题下、日夜切换条） |

### 2.3 品牌/功能色

| Token | Hex | 用途 |
|-------|-----|------|
| `gold-primary` | `#C9A24B` | 主操作按钮、当前选中、钟面刻度、"我"的座位标记 |
| `gold-bright` | `#E4CC85` | 高光：钟针、当前天数、聚焦态 |
| `blood` | `#B84A55` | 邪恶阵营、死亡、处决、危险操作、矛盾警告 |
| `ink-violet` | `#8E86B8` | 次要信息、未激活态 |

### 2.4 语义状态色（信任度 / 信息可靠性）

刻意避开霓虹绿/纯黄，与烛光世界协调；**每级同时配图标/文字标签，不单靠颜色**（色弱友好）：

| 信任度 (TrustLevel) | 色 | Hex | 图形记号 |
|------|-----|-----|----------|
| confirmed_good 确信好人 | 苔绿 | `#57A773` | 实心盾 ✓ |
| likely_good 偏好 | 月白青 | `#8FB8A8` | 空心盾 |
| unknown 未知 | 石板灰紫 | `#7E7A99` | 问号 ? |
| suspect 嫌疑 | 烬橙 | `#D0874A` | 半焰 ⚠ |
| demon_candidate 恶魔候选 | 血红 | `#B84A55` | 恶魔角 ☠ |

| 信息可靠性 (Reliability) | 色 | Hex |
|------|-----|-----|
| verified 已验证 | `#57A773` | |
| unverified 待验证 | `#8E86B8` | |
| possibly_tainted 可能醉/毒 | `#D0874A` | |
| invalidated 已失效 | `#4A4468`（整体降透明度 50%） | |

### 2.5 文字色

| Token | Hex | 对比度（对 bg-base） |
|-------|-----|------|
| `text-primary` | `#EDE6D6`（羊皮纸白） | ≈13.5:1 ✅ |
| `text-secondary` | `#A79FC4` | ≈6.2:1 ✅ |
| `text-disabled` | `#5C5680` | 仅用于禁用态 |
| `text-on-gold` | `#1A1426` | 金底上的深墨字 |

### 2.6 禁止事项

- ❌ 纯黑 `#000000` / 纯白 `#FFFFFF` 直接使用（破坏烛光感，用上面的近黑近白替代）
- ❌ 霓虹/高饱和点缀色（Material 默认紫 `#6750A4`、荧光绿等）
- ❌ 大面积血红色块（血红只作信号色）
- ❌ 金色大面积铺底（金色是烛光，不是墙纸）

## 三、字体排印

中文优先、纯离线 → **字体文件打包进 assets，不用联网字体服务**。

| 角色 | 字体 | 用途 |
|------|------|------|
| 展示体 Display | **Noto Serif SC（思源宋体）Bold/SemiBold** | 屏幕大标题、天数"第 N 天"、钟面座位数字、玩家详情页角色名。衬线的"刻印感"是哥特气质的主要来源 |
| 正文/操作体 | **Noto Sans SC（思源黑体）Regular/Medium** | 正文、按钮、标签、表单、列表——Operate 界面一律无衬线 |
| 数字/计时 | Noto Serif SC（与展示体一致） | 钟面刻度、投票计数等"仪式感数字" |

字阶（固定刻度，ratio ≈ 1.2；单位 sp，跟随系统字号）：

| Token | 字号/行高 | 字重 | 用途 |
|-------|-----------|------|------|
| `display` | 28/36 | Serif Bold | 页面主标题（每屏至多一处） |
| `title` | 20/28 | Serif SemiBold | 卡片标题、天数标题、角色名 |
| `headline` | 17/24 | Sans Medium | 分组标题、面板标题 |
| `body` | 15/22 | Sans Regular | 正文、记录内容 |
| `label` | 13/18 | Sans Medium | 按钮、Tab、表单标签 |
| `caption` | 11/16 | Sans Regular | 辅助说明、时间戳（下限 11sp） |

规则：
- 衬线体**绝不**出现在按钮、表单、正文、数据列表中。
- 中西文混排时数字使用展示体的场合仅限"仪式感数字"。
- 字重只用 Regular/Medium/SemiBold/Bold 四档，不用 Thin/Light（暗底下细字发虚）。

## 四、形状、材质与层级

- **圆角**：卡片/面板 `12`，按钮/输入框 `10`，Chip `8`（全圆角 Stadium 仅用于投票计数等小徽章）。统一刻度，不逐组件发明。
- **描边**：卡片默认 0.5px `line-hairline`；仪式性区块（当标题卡、日夜条）用 0.5px `line-gold`。不用粗描边。
- **层级（Elevation）**：不用投影堆叠，用 `bg-surface-1→2→3` 的明度阶梯表达（Material 3 tonal elevation 思路）。死亡/失效态用降低不透明度表达，不加灰色滤镜块。
- **质感**：允许极轻量的纸纹/皮革噪点（≤4% 不透明度，平铺 PNG，打包进 assets）用于 `bg-base`；禁止玻璃拟态、渐变发光按钮。
- **图标**：线性图标（1.5px  stroke，圆角端点）。iOS 用 SF Symbols，Android 用 Material Symbols，风格统一取"细线+几何"。角色图标（22 个 TB 角色）后续定制一套细线徽章风 glyph（Phase 1 可先用文字缩写代替）。
- **分隔**：标题下的金色刻度线（中间小菱形 ◆ 收束）是手札的签名装饰，只用于 `display`/`title` 级标题下。

## 五、间距与布局

- **4pt 网格**：间距 token `4 / 8 / 12 / 16 / 24 / 32 / 48`。
- 页面安全区内边距 `16`；卡片内边距 `16`；列表项垂直间距 `8`。
- 触控目标：iOS ≥44×44pt，Android ≥48×48dp，相邻目标间距 ≥8。
- 标题上方留白恒大于下方（节奏感）。
- 对局主界面信息密度优先：座位圆环直径 ≈ 屏宽 85%，始终完整可见；当日面板默认半屏高度，可上滑全屏、下滑收起。

## 六、核心组件规范

### 6.1 座位圆环（钟面）⭐ 签名组件

- **构成**：金色细线刻度环 + 玩家座位（圆形节点，直径 56dp，含名字缩写 + 信任度色环 2.5px）+ 中心区域显示"第 N 天 · 昼/夜"（日月图标 + 衬线数字）。
- **状态**：
  - 存活：节点底 `bg-surface-2`，金线刻度。
  - 自己：节点外圈 `gold-bright` 2px 实线 + 微光晕（box-shadow 30% 金，仅此处允许发光）。
  - 死亡：节点整体降至 35% 不透明度 + 斜向细划线 + 骷髅小角标；**占位不消失**（座位收缩公理要求物理保留）。
  - 被提名/处决动画中：血红色环呼吸脉冲一次（400ms 一次，不循环）。
- **交互**：点按 → 弹出玩家信息卡（底部弹层）；长按 → 快捷操作菜单（标记死亡/信任度/备注）；选中某玩家时其存活邻座以 `gold-bright` 描边高亮。
- **数字**：5-15 人时座位节点等分圆周，12 点方向为 1 号位，顺时针排列——与真实钟楼钟面同构。

### 6.2 当日信息面板（Day Panel）

- 顶部：日夜切换 segmented control（昼 ☀ / 夜 ☾，金色当前态）。
- 信息分组卡片：夜死 / 角色声明 / 信息声明 / 提名投票 / 备注，每组 `headline` + 金色刻度线。
- 录入控件按角色模板自适应（数字步进器、双人选择器、角色选择器等），全部满足 ≤3 次点击。
- 关键操作（确认死亡、确认处决）：血红色 outlined 按钮 + 二次确认 dialog。

### 6.3 按钮体系

| 类型 | 样式 | 用途 |
|------|------|------|
| Primary | `gold-primary` 实底 + `text-on-gold` 深字 | 每屏唯一主操作（如"记录夜晚信息"） |
| Tonal | `bg-surface-3` 底 + `gold-bright` 字 | 次操作 |
| Outlined | 0.5px 金/灰紫描边 + 文字 | 辅助操作 |
| Destructive | 0.5px `blood` 描边 + `blood` 字 | 死亡/处决/删除（需确认） |
| Text | 无底色 | 三级操作 |

所有按钮具备 default / pressed（加深 8%）/ disabled（40% 不透明度）三态；禁用 hover 概念，不做 web 式悬浮效果。

### 6.4 其他

- **底部弹层（Bottom Sheet）**：录入与玩家详情一律用 bottom sheet（`bg-surface-2`），不用全屏 dialog 打断对局流。
- **矛盾警告条**：`blood` 0.5px 描边 + 12% `blood` 底 + ⚠ 图标 + 一句话说明 + "查看"入口；呈现在相关玩家卡和面板顶部——气质上是"手札边角浮现的疑点批注"，不是系统报错。
- **空状态**：用一句话教用户下一步（如"点击座位上的玩家，记录 TA 的角色声明"），配 40% 透明度的钟面线稿插画；不放"暂无数据"四个字。
- **列表**：设置/历史局使用平台分组列表（iOS inset grouped / Android Material list），不发明卡片堆。

## 七、动效

原则：**动效表达状态，不表演**。常规过渡 150–250ms（Material 标准缓动）；装饰性编排只允许出现在三处签名时刻：

1. **昼夜更替**：切换昼/夜时，圆环中心的日月图标沿弧线旋转交替 + 背景色温微调（≤600ms，一次完成）。
2. **死亡（蜡烛熄灭）**：标记死亡时，该座位节点亮度在 400ms 内缓缓压暗至 35%，伴随一缕上升 12dp 消散的"烟"（单个粒子即可）。
3. **处决确认**：血红色环自 12 点方向扫过该座位（如钟针扫过），300ms。

约束：
- 支持系统 Reduce Motion / 移除动画：退化为 150ms 交叉淡入。
- 列表滚动、录入操作**零编排动画**——对局中不让人等动画。
- 不允许循环播放的装饰动画（呼吸灯只允许一次性脉冲）。

## 八、平台适配要点

| 项 | iOS | Android |
|----|-----|---------|
| 导航 | 底部 Tab（对局/时间线/存档/设置），NavigationStack 层级 | NavigationBar（同构 3–4 项）， predictive Back 必须可用 |
| 手势 | 左缘右滑返回永远保留 | 系统 Back 永远可用，不拦截 |
| 触控 | ≥44pt | ≥48dp，edge-to-edge + window insets |
| 控件 | 系统 sheet、context menu、alert | Material dialog、snackbar（瞬时反馈用 snackbar，不用 toast） |
| 字体 | 打包字体 + 跟随 Dynamic Type | 打包字体 + sp 单位跟随系统字号 |

主题在 Flutter 侧实现为单一 `ColorScheme`（dark）+ 自定义 `ThemeExtension`（信任度/可靠性/材质色板），保证语义 token 不散落代码中。

## 九、落地检查清单（每个新屏自查）

1. 底色、文字、语义色全部来自 token，无硬编码 hex？
2. 衬线体只出现在 display/title 级？
3. 主操作唯一且为金色实底？
4. 触控目标 ≥44/48，关键破坏操作有确认？
5. 暗底对比度 AA（正文 ≥4.5:1）？
6. 状态色有配套的图形/文字记号（非纯颜色）？
7. 动效 ≤250ms（签名时刻除外）且可降级？
8. 无纯黑/纯白、无霓虹色、无玻璃拟态、无渐变发光？
